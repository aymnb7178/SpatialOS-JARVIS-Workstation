مساحة عمل مجسّمات ثلاثية الأبعاد (هولوغرام) تعمل بكاميرا الويب، مبنية بلغة بايثون مع OpenCV وMediaPipe. تستطيع بإيماءات يدك الإمساك بالمجسمات وتدويرها وتكبيرها وتقسيمها وتثبيتها فوق صورة الكاميرا. ويقابلها عقل مركزي "J.A.R.V.I.S." قائم على القواعد يفهم أوامر بالعربية والإنجليزية، ويدير الذاكرة وصلاحيات الأدوات، وسجلاً من 15 وكيلاً متخصصاً.

مشروع شخصي لمطوّر واحد. يذكر هذا الملف بوضوح ما هو منفّذ وما ليس منفّذاً. راجع [القيود الحالية](#القيود-الحالية) و[FEATURE_MATRIX.md](FEATURE_MATRIX.md).

## ما الذي تم التحقق منه

- **نجحت 16 اختباراً آلياً** (10 للعقل المركزي و6 لمحرك الرؤية والفيزياء)، وشُغّلت على بايثون 3.13 داخل بيئة لينكس بدون شاشة.
- **جرّبها المؤلف يدوياً (ويندوز وكاميرا ويب):** فُتحت الكاميرا وتتبّعت اليد، وفتح مشغّل التطبيقات المعتمدة الآلة الحاسبة والمفكرة ونافذة طرفية بعد التأكيد. وهذه بدون اختبارات آلية.
- **لم تُجرَّب بعد:** الميكروفون، النطق الصوتي، قراءة النصوص (OCR)، ومرساة الواقع المعزز.
- **لا يوجد ادعاء بأداء معيّن.** البرنامج *يطلب* من الكاميرا دقة 1280×720 بمعدل 60 إطاراً (`cv2.CAP_PROP_FPS`)، لكن المعدل الفعلي يتوقف على الجهاز ولم يُقَس.

## المعمارية

المخطط التفصيلي (Mermaid) موجود في [README.md](README.md#architecture). باختصار:

- **مسار الرؤية:** الكاميرا ← تتبع اليد (MediaPipe، 21 نقطة لكل يد) ← فلتر 1-Euro والتوقع الشبحي ← محرك الإيماءات ← محرك الفيزياء ← العارض ثلاثي الأبعاد ← العوالم الأربعة.
- **مسار العقل المركزي:** الصوت أو لوحة المفاتيح ← محلل الأوامر (قائم على الكلمات المفتاحية) ← الأدوات والمشرف الأمني + الوكلاء الـ 15 ← مراقب الجودة ← ذاكرة SQLite.

## العقل المركزي J.A.R.V.I.S.

- **فهم الأوامر:** يكتشف العربية أو الإنجليزية ويربط الكلمات المفتاحية بمهام فرعية ووكلاء وأدوات. هو محلل قائم على القواعد، وليس نموذجاً لغوياً.
- **الذاكرة (5 طبقات):** عاملة (في الذاكرة المؤقتة، آخر 25 دورة حوار)، عرضية، دلالية (مع درجة ثقة ومصدر)، مشاريع، وتفضيلات، والأربع الأخيرة في SQLite. ترفض الذاكرة النصوص التي تشبه الأسرار (`password`, `token`, `sk-...`) ويحجبها فلتر السجلات.
- **الأمان والأدوات:** لا تعمل إلا الأدوات المسجّلة. مستوى `LOW` يُنفَّذ فوراً، و`MEDIUM` و`HIGH` يعيدان رمز تأكيد وينتظران **Y**. حارس تكرار لمدة 3 ثوانٍ، وماسح لخمسة أنماط حقن معروفة، وبصمة SHA-256 للملفات. مشغّل التطبيقات لا يفتح إلا الآلة الحاسبة والمفكرة وموجّه الأوامر، وعلى ويندوز فقط. الأداة الوحيدة من مستوى `HIGH` هي أداة وهمية لا تحذف شيئاً.
- **بوابة النماذج:** `UnifiedModelGateway` قادرة على استدعاء OpenAI إذا ضُبط `OPENAI_API_KEY`، وإلا ترجع نصاً ثابتاً بديلاً. العقل المركزي ينشئها لكن لا شيء في المسار الحالي يستدعيها. مفتاح `GEMINI_API_KEY` يُكتشف فقط، ولا يوجد تكامل مع Gemini في هذا الكود.

## التثبيت والتشغيل

**المتطلبات:** بايثون 3.9 أو أحدث، وكاميرا ويب (يوجد في الكود بديل بالفأرة عند غياب الكاميرا لكنه لم يُجرَّب)، واتصال بالإنترنت عند أول تشغيل لتنزيل نموذج `hand_landmarker.task` الخاص بـ MediaPipe.

```bash
git clone https://github.com/aymnb7178/SpatialOS-JARVIS-Workstation.git
cd SpatialOS-JARVIS-Workstation
python -m venv .venv
source .venv/bin/activate          # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
python stark_omni_workstation.py
```

**حزم اختيارية:** `SpeechRecognition` مع `PyAudio` للإدخال الصوتي، و`pytesseract` مع برنامج Tesseract لقراءة النصوص كاملة. النطق الصوتي ومشغّل التطبيقات يعتمدان على ميزات ويندوز.

**مفتاح API اختياري:** الكود يقرأ متغيرات البيئة الحقيقية ولا يحمّل ملف `.env` تلقائياً. انسخ `.env.example` كمرجع وصدّر القيم يدوياً:

```bash
export OPENAI_API_KEY="your-key"           # ويندوز PowerShell: $env:OPENAI_API_KEY = "your-key"
```

لا ترفع مفاتيح حقيقية إلى Git. الملف `.env` مُستثنى في `.gitignore`.

## القيود الحالية

- فهم الأوامر يعتمد على كلمات مفتاحية، وقد يخطئ في صياغات لا تحتويها.
- أحد عشر وكيلاً من خمسة عشر يكتفون بالإقرار بالمهمة. مسار "التنفيذ الذاتي" يشغّل أدوات ووكلاء يُختارون بالكلمات المفتاحية، وليس نظام وكلاء متعدد يقرر بنفسه.
- بوابة النماذج غير موصولة بالمسار، والبديل المحلي نص ثابت.
- أداة المستوى `HIGH` وهمية، والروبوتات محاكاة فقط.
- المسافة بالسنتيمتر تقدير غير معايَر.
- سرعة تشغيل التسجيل ثابتة على 1.0x.
- النطق الصوتي وتشغيل التطبيقات على ويندوز فقط، وقياس الذاكرة غير متاح على macOS.
- التعرف على الصوت يستخدم خدمة عبر الإنترنت.
- لا يوجد قياس لمعدل الإطارات.
- مُصدِّر `[E]` المدمج يكتب جدول ميزات أكثر تفاؤلاً من الواقع، فاعتمد `FEATURE_MATRIX.md` مرجعاً.
